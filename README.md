## 💎 Sobre o Projeto
Este e-commerce foi desenvolvido sob medida para a marca **Maely Cristina**. Diferente de soluções prontas, o site foi construído do zero para oferecer uma experiência de compra fluida no mobile, gestão de estoque rigorosa e um sistema de fidelização de clientes focado em atendimento personalizado.

---

## ✨ Funcionalidades em Destaque

### 💳 Checkout de Alta Conversão
*   **Pagamentos Integrados:** Checkout transparente com Mercado Pago (Cartão de Crédito e Débito).
*   **Incentivo ao PIX:** Sistema inteligente que aplica 5% de desconto automaticamente sobre o valor das peças para pagamentos via PIX.
*   **Sincronização via Webhook:** O status do pedido e o estoque são atualizados em tempo real assim que o pagamento é confirmado pelo banco.

### 📦 Gestão de Estoque por Grade (Inovação)
*   **Controle por Variação:** O sistema gerencia o estoque individualmente por **Cor e Tamanho** (ex: Vestido Preto P, Rosa M).
*   **Filtro Inteligente:** Na página do produto, o sistema desabilita e risca automaticamente os tamanhos que não possuem estoque para a cor selecionada.
*   **Proteção de Venda:** Travas de segurança impedem que o cliente adicione ao carrinho mais unidades do que o saldo real disponível.

### 🖼️ Painel Administrativo Autônomo
*   **Banners Dinâmicos:** Gestão completa de banners com suporte a arquivos diferentes para Desktop (Horizontal) e Mobile (Vertical), garantindo o melhor visual em qualquer tela.
*   **Controle de Cupons:** Criação de cupons de desconto com data de validade e limite de uso por CPF.
*   **Dashboard Financeiro:** Resumo de vendas, pedidos pendentes e logística de entrega.

### 🎂 CRM e Fidelização (Mimos)
*   **Perfil Progressivo:** Área do cliente para gestão de endereço e data de nascimento.
*   **Painel de Aniversariantes:** O Admin possui uma central que filtra clientes que fazem aniversário no mês, com integração direta ao WhatsApp para envio de cupons de presente.

---

## 🛠️ Tecnologias Utilizadas

*   **Backend:** Node.js com Framework Express.
*   **Frontend:** EJS (Embedded JavaScript templates) para renderização dinâmica e CSS3 para design responsivo (Mobile First).
*   **Banco de Dados:** Firebase Firestore (NoSQL) para alta performance em tempo real.
*   **Autenticação:** Firebase Auth (Login via Google, E-mail ou Telefone).
*   **Pagamentos:** Mercado Pago SDK V2.
*   **Imagens:** Cloudinary (CDN de alta velocidade para carregamento de fotos).
